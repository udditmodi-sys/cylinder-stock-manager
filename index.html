Employee access

For this small team, create employee accounts in Firebase Console → Authentication → Users → Add user. Give each employee their own login; do not share passwords.

  1. Enable Email/Password provider in Firebase Authentication.
  2. Create one account for each employee.
  3. Add the user's email and role in Firestore under users/{uid}, e.g. { email: "employee@company.com", role: "employee", active: true }.
  4. For the administrator, set role to admin.
This app's included rules allow signed-in active users to manage stock data. Admin-only account/role management should be done through the Firebase Console or a trusted server process. Never allow employees to edit their own role.
